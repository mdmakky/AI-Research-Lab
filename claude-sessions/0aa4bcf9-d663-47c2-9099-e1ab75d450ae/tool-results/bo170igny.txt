## Contradictions
<!-- Findings that disagree: which papers, what differs (data, method, population, metric), likely explanation (INTERPRETATION). -->

1. **Language direction (RQ1).** JavaScript > Python in [@spracklen2024we, p. 7] (per-test means 21.3% vs 15.8%); Python > JavaScript in [@krishna2025importing, p. 8] (23.14% vs 14.73%, per prompt) and for every model in [@churilov2026range, p. 7] (per mention). Differences: extraction (Spracklen asks the model for package lists and parses install commands and rejects import parsing, [@spracklen2024we, p. 6]; Krishna and Churilov parse imports, [@krishna2025importing, p. 12]; [@churilov2026range, p. 5]), unit (mention vs prompt), model cohort (2023–24 vs 2025–26). [I] Import parsing over-count
2. **Prompt source on the same corpus (RQ1/RQ4).** Stack Overflow prompts > LLM-generated prompts for almost every model in [@spracklen2024we, p. 20]; LLM-generated > Stack Overflow for every model in [@churilov2026range, p. 7]. Same released prompt corpus, different models, extraction and time (2024 vs 2026). [I] Cleanest contradiction in the set; cause unresolved.
3. **Model size (RQ1).** Larger models hallucinate less in [@krishna2025importing, p. 6] (r = −0.542, but 33 pseudo-replicated points and an estimated 200B GPT-4o size, [@krishna2025importing, p. 3]); no size effect for Rust in [@zheng2026when, p. 6]; newer Llama-3.1-8B produced more unique hallucinated names than Llama-3-8B in [@zhao2025hfuzzer, p. 7]. [I] Size is confounded with quantization (GPTQ for all open models in [@spracklen2024we, p. 6]; 4-bit ≤32B in [@dasu2026refusing, p. 10]; explicit quantization effects in [@haque2025secure, p. 6]).
4. **Temperature (RQ1).** Rates rise sharply above temperature 1 in [@spracklen2024we, p. 8]; no effect from 0 to 2 for Rust in [@zheng2026when, p. 6]. Different ecosystem and extraction; not resolved.
5. **Import names: valid or hallucinated? (RQ4).** [@twist2026library, p. 4] counts any import name registered on PyPI as valid (PyPA normalisation only, [@twist2026library, p. 15]); [@raj2026names, p. 8] flags registered import names such as pil and faiss as squats; [@djire2026evaluating, p. 6] validates code-generation imports against the registry, so unregistered import names (cv2) probably count as hallucinations. [I] Method-driven contradiction: the field has no shared import→distribution mapping.
6. **RAG effect size (RQ3).** Large reductions in Python in [@spracklen2024we, p. 13] (CodeLlama 26.28% → 13.40%); negligible in Rust in [@zheng2026when, p. 8]; RAG slightly raises hallucination in [@liu2026packmonitor, p. 13] and raises JavaScript PHR in [@djire2026evaluating, p. 6]. [I] RAG is ecosystem- and retriever-dependent and not a reliable defence on its own.
7. **Real-world registration (RQ2) — compatible, not contradictory.** 25 of 2,282 hallucinated names registered within about six months, one with malware [@churilov2026range, p. 12]; 0 of 1,641 private names registered after 4 days and 22 of 149 public names registered, none malicious, 19 defensive placeholders [@okwor2026hallucination, p. 5]. Different windows and sampling frames.

## Agreements / converging evidence

- Every study that measures it finds non-zero package hallucination in all tested models, from 2023–24 open models ([@spracklen2024we, p. 7]) to 2026 frontier models ([@churilov2026range, p. 6]), and in Rust and Go as well as Python/JS ([@zheng2026when, p. 5]; [@haque2025secure, p. 6]).
- Hallucinated names are mostly model-specific with a persistent shared core: 81% single-model names in [@spracklen2024we, p. 10]; 104 names shared by all five 2026 models in [@churilov2026range, p. 9]; 450 of 455 new names single-model in [@okwor2026hallucination, p. 4]. Many recur across re-runs (43% in 10/10 runs, [@spracklen2024we, p. 9]).
- Registry existence checks are necessary but not sufficient: registered lookalikes and import-name collisions pass a plain 200/404 check ([@raj2026names, p. 8]; [@liu2026packmonitor, p. 6]; [@spracklen2024we, p. 12]).
- White-box defences (logit masking, model editing, unlearning) reach large reductions but need weights or logits and GPU servers ([@liu2026packmonitor, p. 12]; [@liu2026mitigating, p. 6]; [@spracklen2026llm, p. 8]); only static analysis ran on a laptop-class machine ([@mirandapena2026empirical, p. 17]).
- Models largely accept user-supplied fake package names (compliance, not invention): [@djire2026evaluating, p. 9]; [@twist2026library, p. 6]; [@dasu2026refusing, p. 8].
